## `client.SubscriptionRenewals.CreateScheduledRenewalConfigurationItem` — `POST /subscriptions/{subscription_id}/scheduled_renewals/{scheduled_renewals_configuration_id}/configuration_items.json` (`createScheduledRenewalConfigurationItem`)

- **loud**, account-config/errors: With list vs sales pricing enabled, list_price_point_id names a price point that does not exist → 422 "list_price_point_id not found". **Do:** Send an existing list price point id. Also: `updateScheduledRenewalConfigurationItem`. *(spec `spec/openapi.yaml`; spec `spec/openapi.yaml`; `maxio-c4:createScheduledRenewalConfigurationItem.2`)*
- **loud**, account-config/errors: With list vs sales pricing enabled, list_price_point_id names a custom (subscription-specific) price point → 422 "list_price_point_id must reference a non-custom product price point". **Do:** Point list_price_point_id at a catalog (non-custom) price point. Also: `updateScheduledRenewalConfigurationItem`. *(spec `spec/openapi.yaml`; spec `spec/openapi.yaml`; `maxio-c4:createScheduledRenewalConfigurationItem.3`)*
- **loud**, account-config/errors: With list vs sales pricing enabled, list_price_point_id belongs to a different product or component than the item → 422 "list_price_point_id must belong to the same product". **Do:** Use a list price point of the same product or component as the item. Also: `updateScheduledRenewalConfigurationItem`. *(spec `spec/openapi.yaml`; spec `spec/openapi.yaml`; `maxio-c4:createScheduledRenewalConfigurationItem.4`)*
- **loud**, -/errors: A component item's custom_price for an on/off component has more than one price bracket starting at 1 → outcome not stated. **Do:** Send a single price bracket starting at 1 for on/off components. Also: `updateScheduledRenewalConfigurationItem`. **Conflict:** The schema lists pricing_scheme as required while its description says to omit it for on/off components; the record covers only the price bracket rule, which both agree with. *(spec `spec/components/schemas/Scheduled-Renewal-Component-Custom-Price.yaml`; spec `spec/components/schemas/Scheduled-Renewal-Component-Custom-Price.yaml`; `maxio-c4:createScheduledRenewalConfigurationItem.5`)*
- **silent**, account-config/values: renewal_configuration_item.custom_price.list_price_point_id is sent on a site with list vs sales pricing disabled → The parameter is ignored, with no validation or behavioral impact.. **Do:** Rely on list_price_point_id only when list vs sales pricing is enabled. Also: `updateScheduledRenewalConfigurationItem`. **Conflict:** The item custom price schemas declare additionalProperties: false without a list_price_point_id property, while both operation descriptions accept it; the record follows the descriptions. *(spec `spec/openapi.yaml`; spec `spec/openapi.yaml`; `maxio-c4:createScheduledRenewalConfigurationItem.1`)*
