# Subscriptions and their lifecycle

- **loud**, order/errors (`client.Subscriptions.ApplyCouponsToSubscription`): A coupon code that does not exist is applied → 422 "Coupon code could not be found.". **Do:** Apply only existing coupon codes. *(`maxio-c4:applyCouponsToSubscription.2`)*
- **loud**, state/errors (`client.SubscriptionStatus.CancelSubscription`, `client.SubscriptionStatus.InitiateDelayedCancellation`): The subscription is already canceled → 422 "The subscription is already canceled". **Do:** Check the state before canceling and treat this 422 as already done. *(`maxio-c4:cancelSubscription.6`)*
- **loud**, limits/errors (`client.SubscriptionStatus.CancelSubscription`, `client.SubscriptionStatus.InitiateDelayedCancellation`): reason_code is longer than 255 characters → 422 "reason_code size cannot be greater than 255". **Do:** Keep reason_code at 255 characters or fewer. *(`maxio-c4:cancelSubscription.7`)*
- **loud**, limits/errors (`client.SubscriptionStatus.CancelSubscription`, `client.SubscriptionStatus.InitiateDelayedCancellation`): cancellation_message is longer than 65535 characters → 422 "cancellation_message size cannot be greater than 65535". **Do:** Keep cancellation_message at 65535 characters or fewer. *(`maxio-c4:cancelSubscription.8`)*
- **loud**, account-config/errors (`client.SubscriptionRenewals.CreateScheduledRenewalConfiguration`, `client.SubscriptionRenewals.UpdateScheduledRenewalConfiguration`): contract_id or create_new_contract is sent on a site without Contracts enabled → outcome not stated. **Do:** Send contract fields only when Contracts are enabled for the site. *(`maxio-c4:createScheduledRenewalConfiguration.2`)*
- **loud**, account-config/errors (`client.SubscriptionRenewals.CreateScheduledRenewalConfigurationItem`, `client.SubscriptionRenewals.UpdateScheduledRenewalConfigurationItem`): With list vs sales pricing enabled, list_price_point_id names a price point that does not exist → 422 "list_price_point_id not found". **Do:** Send an existing list price point id. *(`maxio-c4:createScheduledRenewalConfigurationItem.2`)*
- **loud**, account-config/errors (`client.SubscriptionRenewals.CreateScheduledRenewalConfigurationItem`, `client.SubscriptionRenewals.UpdateScheduledRenewalConfigurationItem`): With list vs sales pricing enabled, list_price_point_id names a custom (subscription-specific) price point → 422 "list_price_point_id must reference a non-custom product price point". **Do:** Point list_price_point_id at a catalog (non-custom) price point. *(`maxio-c4:createScheduledRenewalConfigurationItem.3`)*
- **loud**, account-config/errors (`client.SubscriptionRenewals.CreateScheduledRenewalConfigurationItem`, `client.SubscriptionRenewals.UpdateScheduledRenewalConfigurationItem`): With list vs sales pricing enabled, list_price_point_id belongs to a different product or component than the item → 422 "list_price_point_id must belong to the same product". **Do:** Use a list price point of the same product or component as the item. *(`maxio-c4:createScheduledRenewalConfigurationItem.4`)*
- **loud**, -/errors (`client.SubscriptionRenewals.CreateScheduledRenewalConfigurationItem`, `client.SubscriptionRenewals.UpdateScheduledRenewalConfigurationItem`): A component item's custom_price for an on/off component has more than one price bracket starting at 1 → outcome not stated. **Do:** Send a single price bracket starting at 1 for on/off components. *(`maxio-c4:createScheduledRenewalConfigurationItem.5`)*
- **loud**, -/errors (`client.Subscriptions.CreateSubscription`, `client.Subscriptions.PreviewSubscription`, `client.ProformaInvoices.CreateSignupProformaInvoice`, `client.ProformaInvoices.PreviewSignupProformaInvoice`): The subscription body names neither product_handle nor product_id, uses no offer_id, and is not a components-only subscription under the new Catalog experience → outcome not stated. **Do:** Identify the product with product_handle or product_id (or pass offer_id) unless building a components-only subscription on a Catalog-experience site. *(`maxio-c4:createSubscription.1`)*
- **loud**, order/- (`client.Subscriptions.CreateSubscription`, `client.Products.CreateProduct`): A subscription is to be sold for a product that has not been created → outcome not stated. **Do:** Create and configure the product before creating subscriptions to it. *(`maxio-c4:createSubscription.101`)*
- **loud**, order/errors (`client.Subscriptions.CreateSubscription`): payment_profile_id does not name an existing card or bank account belonging to an existing customer → outcome not stated. **Do:** Use payment_profile_id only for a stored profile of an existing customer; otherwise send payment_profile_attributes. *(`maxio-c4:createSubscription.16`)*
- **loud**, account-config/errors (`client.Subscriptions.CreateSubscription`, `client.Subscriptions.PreviewSubscription`): On a site with the new Catalog experience, a subscription is sent without product_id or product_handle and has no active component with a positive allocated_quantity, a positive unit_balance, enabled: true, or a configured metered component → outcome not stated. **Do:** Only omit the product on a Catalog-experience site, and then include at least one active qualifying component. *(`maxio-c4:createSubscription.2`)*
- **loud**, other/- (`client.Subscriptions.CreateSubscription`, `client.Subscriptions.UpdateSubscription`): The app tries to change the currency of an existing subscription → outcome not stated. **Do:** Choose the subscription currency at signup; it cannot be changed afterwards. *(`maxio-c4:createSubscription.36`)*
- **loud**, -/errors (`client.Subscriptions.CreateSubscription`, `client.Subscriptions.UpdateSubscription`): snap_day is not a day from 1 to 28 or 'end' → outcome not stated. **Do:** Send snap_day as 1 to 28 or 'end'. *(`maxio-c4:createSubscription.40`)*
- **loud**, account-config/errors (`client.Subscriptions.CreateSubscription`, `client.Subscriptions.UpdateSubscription`): payment_collection_method is not valid for the site's architecture (statements: automatic or invoice; Relationship Invoicing: automatic, remittance or prepaid) → outcome not stated. **Do:** Pick the collection method from the set allowed by the site's invoicing architecture. *(`maxio-c4:createSubscription.41`)*
- **loud**, account-config/errors (`client.Subscriptions.CreateSubscription`, `client.Subscriptions.UpdateSubscription`): branding_theme_id is sent on a site without Branding Themes enabled → outcome not stated. **Do:** Send branding_theme_id only when Branding Themes are enabled for the site. *(`maxio-c4:createSubscription.49`)*
- **loud**, limits/errors (`client.Subscriptions.CreateSubscription`, `client.Subscriptions.UpdateSubscription`, `client.SubscriptionGroups.SignupWithSubscriptionGroup`, `client.Subscriptions.PreviewSubscription`, `client.ProformaInvoices.CreateSignupProformaInvoice`, `client.ProformaInvoices.PreviewSignupProformaInvoice`): A custom_price would give the subscription more than 30 custom price points → outcome not stated. **Do:** Keep each subscription at 30 custom price points or fewer. *(`maxio-c4:createSubscription.55`)*
- **loud**, account-config/errors (`client.Subscriptions.CreateSubscription`, `client.Subscriptions.UpdateSubscription`): A component custom_price sets interval or interval_unit on a site without Multifrequency → outcome not stated. **Do:** Set component custom price intervals only on Multifrequency-enabled sites. *(`maxio-c4:createSubscription.56`)*
- **loud**, -/errors (`client.Subscriptions.CreateSubscription`, `client.Subscriptions.UpdateSubscription`): A custom_price for an on/off component includes a pricing_scheme or more than one price bracket starting at 1 → outcome not stated. **Do:** For on/off components omit pricing_scheme and send one price bracket starting at 1. *(`maxio-c4:createSubscription.57`)*
- **loud**, other/errors (`client.Subscriptions.CreateSubscription`, `client.SubscriptionStatus.RetrySubscription`, `client.SubscriptionStatus.ReactivateSubscription`, `client.SubscriptionProducts.MigrateSubscriptionProduct`): A payment taken by the call requires 3D Secure authentication under Strong Customer Authentication → 422 "action_link" The request enters a post-authentication flow; the response carries an action_link that directs the customer through 3DS authentication. **Do:** Treat a 422 carrying an action_link as a 3DS challenge: send the customer to the link and complete the post-authentication flow. *(`maxio-c4:createSubscription.8`)*
- **loud**, -/errors (`client.SubscriptionNotes.CreateSubscriptionNote`, `client.SubscriptionNotes.UpdateSubscriptionNote`): The note body is blank → 422 "Body: cannot be blank.". **Do:** Send a non-empty note body. *(`maxio-c4:createSubscriptionNote.1`)*
- **loud**, auth/errors (`client.SalesCommissions.ListSalesCommissionSettings`, `client.SalesCommissions.ListSalesReps`, `client.SalesCommissions.ReadSalesRep`): A Sales Commission request is authenticated with a site API key instead of a user API key → outcome not stated. **Do:** Generate a user API key and send it as a Bearer Authorization header for Sales Commission calls. *(`maxio-c4:listSalesCommissionSettings.1`)*
- **loud**, auth/- (`client.SalesCommissions.ListSalesCommissionSettings`, `client.SalesCommissions.ListSalesReps`, `client.SalesCommissions.ReadSalesRep`): Seller-level resources (sales commission settings and sales reps) are requested → outcome not stated. **Do:** Authenticate these calls with a user API key generated from the API Token View, not a site API key. *(`maxio-c4:listSalesCommissionSettings.101`)*

- **loud**, auth/- (`client.SalesCommissions.ListSalesCommissionSettings`, `client.SalesCommissions.ListSalesReps`, `client.SalesCommissions.ReadSalesRep`): A user API key is regenerated (or deprecated) → The old key is deprecated and only the new key is valid. **Do:** Replace the stored user API key right after regenerating it. *(`maxio-c4:listSalesCommissionSettings.103`)*
- **loud**, auth/errors (`client.SalesCommissions.ListSalesCommissionSettings`, `client.SalesCommissions.ListSalesReps`, `client.SalesCommissions.ReadSalesRep`): The user whose API key is used does not have financial access → outcome not stated. **Do:** Use the key of a user with financial access. *(`maxio-c4:listSalesCommissionSettings.2`)*
- **loud**, account-config/errors (`client.SalesCommissions.ListSalesCommissionSettings`, `client.SalesCommissions.ListSalesReps`, `client.SalesCommissions.ReadSalesRep`): The seller does not have the Advanced Analytics component enabled → outcome not stated. **Do:** Have Advanced Analytics enabled for the seller (via Maxio support) before using these endpoints. *(`maxio-c4:listSalesCommissionSettings.3`)*
- **loud**, other/- (`client.SalesCommissions.ListSalesCommissionSettings`, `client.SalesCommissions.ListSalesReps`, `client.SalesCommissions.ReadSalesRep`): A Sales Commission request is sent to a site subdomain instead of the seller-level app host → outcome not stated. **Do:** Send Sales Commission requests to the app subdomain, not the site's subdomain. *(`maxio-c4:listSalesCommissionSettings.4`)*
- **loud**, auth/errors (`client.SalesCommissions.ListSalesCommissionSettings`, `client.SalesCommissions.ListSalesReps`, `client.SalesCommissions.ReadSalesRep`): The user's API Token View access has been removed → The user's API key is automatically disabled. **Do:** Use the key of a user who still has API Token View access. *(`maxio-c4:listSalesCommissionSettings.6`)*
- **loud**, auth/errors (`client.SalesCommissions.ListSalesCommissionSettings`, `client.SalesCommissions.ListSalesReps`, `client.SalesCommissions.ReadSalesRep`): The user API key has been regenerated or deprecated → The old key is no longer valid; only the new key works. **Do:** Update stored user API keys after regeneration. *(`maxio-c4:listSalesCommissionSettings.7`)*
