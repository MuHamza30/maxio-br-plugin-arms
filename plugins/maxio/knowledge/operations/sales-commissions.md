# Sales Commissions

## `client.SalesCommissions.ListSalesCommissionSettings` — `GET /sellers/{seller_id}/sales_commission_settings.json` (`listSalesCommissionSettings`)

- **loud**, auth/errors: A Sales Commission request is authenticated with a site API key instead of a user API key → outcome not stated. **Do:** Generate a user API key and send it as a Bearer Authorization header for Sales Commission calls. Also: `listSalesReps`, `readSalesRep`. *(spec `spec/openapi.yaml`; spec `spec/openapi.yaml`; spec `spec/components/parameters/user-authorization.yaml`; announcement `content/help/announcements/2020-04-20-new-api-authentication.md`; `maxio-c4:listSalesCommissionSettings.1`)*
- **loud**, auth/-: Seller-level resources (sales commission settings and sales reps) are requested → outcome not stated. **Do:** Authenticate these calls with a user API key generated from the API Token View, not a site API key. Also: `listSalesReps`, `readSalesRep`. *(spec `spec/openapi.yaml`; announcement `content/help/announcements/2020-04-20-new-api-authentication.md`; `maxio-c4:listSalesCommissionSettings.101`)*
- **loud**, auth/-: A user's API Token View access is removed → The user's API key is automatically disabled. **Do:** Expect seller-level calls with that user's key to fail and issue a key for another enabled user. Also: `listSalesReps`, `readSalesRep`. *(announcement `content/help/announcements/2020-04-20-new-api-authentication.md`; `maxio-c4:listSalesCommissionSettings.102`)*
- **loud**, auth/-: A user API key is regenerated (or deprecated) → The old key is deprecated and only the new key is valid. **Do:** Replace the stored user API key right after regenerating it. Also: `listSalesReps`, `readSalesRep`. *(announcement `content/help/announcements/2020-04-20-new-api-authentication.md`; `maxio-c4:listSalesCommissionSettings.103`)*
- **loud**, auth/errors: The user whose API key is used does not have financial access → outcome not stated. **Do:** Use the key of a user with financial access. Also: `listSalesReps`, `readSalesRep`. *(spec `spec/openapi.yaml`; spec `spec/openapi.yaml`; `maxio-c4:listSalesCommissionSettings.2`)*
- **loud**, account-config/errors: The seller does not have the Advanced Analytics component enabled → outcome not stated. **Do:** Have Advanced Analytics enabled for the seller (via Maxio support) before using these endpoints. Also: `listSalesReps`, `readSalesRep`. *(spec `spec/openapi.yaml`; `maxio-c4:listSalesCommissionSettings.3`)*
- **loud**, other/-: A Sales Commission request is sent to a site subdomain instead of the seller-level app host → outcome not stated. **Do:** Send Sales Commission requests to the app subdomain, not the site's subdomain. Also: `listSalesReps`, `readSalesRep`. *(spec `spec/openapi.yaml`; `maxio-c4:listSalesCommissionSettings.4`)*
- **loud**, auth/errors: The user's API Token View access has been removed → The user's API key is automatically disabled. **Do:** Use the key of a user who still has API Token View access. Also: `listSalesReps`, `readSalesRep`. *(announcement `content/help/announcements/2020-04-20-new-api-authentication.md`; `maxio-c4:listSalesCommissionSettings.6`)*
- **loud**, auth/errors: The user API key has been regenerated or deprecated → The old key is no longer valid; only the new key works. **Do:** Update stored user API keys after regeneration. Also: `listSalesReps`, `readSalesRep`. *(announcement `content/help/announcements/2020-04-20-new-api-authentication.md`; `maxio-c4:listSalesCommissionSettings.7`)*
- **silent**, -/lists: A list request asks for a page past the last page of results → An empty result set is returned, not an error. **Do:** Stop paging when a page comes back empty or shorter than per_page.
