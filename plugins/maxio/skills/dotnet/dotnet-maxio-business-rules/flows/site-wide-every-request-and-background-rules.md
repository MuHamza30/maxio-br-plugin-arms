# Site-wide, every-request and background rules

- **loud**, account-config/- (`client.WebhooksApi.CreateEndpoint`, `client.WebhooksApi.UpdateEndpoint`): A webhook endpoint URL uses plain HTTP while the site is in live mode → outcome not stated. **Do:** Use an HTTPS endpoint URL before taking the site live. *(`maxio-c4:createEndpoint.2`)*
- **loud**, limits/- (`client.CustomFields.CreateMetadata`, `client.CustomFields.UpdateMetadata`): A metadata (custom field) value is larger than 2 KB / 2048 characters → outcome not stated. **Do:** Keep custom field values within 2048 characters (2 KB). *(`maxio-c4:createMetadata.1`)*
- **loud**, limits/- (`client.CustomFields.CreateMetafields`, `client.CustomFields.UpdateMetafield`, `client.CustomFields.CreateMetadata`, `client.CustomFields.UpdateMetadata`): Creating a metafield (directly, by Update Metafield with a new current_name, or implicitly through metadata) would exceed 100 unique metafields for that resource type on the site → outcome not stated. **Do:** Keep at most 100 metafields for subscriptions and 100 for customers per site, and reuse existing metafields. *(`maxio-c4:createMetafields.1`)*
- **loud**, state/- (`client.CustomFields.CreateMetafields`, `client.CustomFields.UpdateMetafield`): A metafield already exists and its resource type (subscriptions or customers) would need to change → outcome not stated. **Do:** Choose the resource type correctly when creating a metafield; create a new metafield on the other resource instead of moving it. *(`maxio-c4:createMetafields.2`)*
- **loud**, -/errors (`client.CustomFields.CreateMetafields`, `client.CustomFields.CreateMetadata`, `client.CustomFields.UpdateMetadata`): A metafield or metadata entry is sent without a name → 422 "'name' must be present to create or update metafields". **Do:** Always send name for every metafield and metadata entry. *(`maxio-c4:createMetafields.3`)*
- **loud**, account-config/- (`client.ApiExports.ExportProformaInvoices`, `client.ApiExports.ReadProformaInvoicesExport`): A proforma invoices export is created or read on a site without Relationship Invoicing → outcome not stated. **Do:** Use proforma invoice exports only on Relationship Invoicing sites. *(`maxio-c4:exportProformaInvoices.1`)*
- **silent**, order/other (`client.Sites.ClearSite`): A site is being moved from test to production (live) mode → Clearing the site data is necessary before the gateway processes real money. **Do:** Clear the site's test data before taking the site live. *(`maxio-c4:clearSite.6`)*
- **silent**, -/other (`client.WebhooksApi.CreateEndpoint`, `client.WebhooksApi.UpdateEndpoint`): A webhook endpoint is hosted on a port other than 80 or 443 → Ports other than 80 and 443 are not supported. **Do:** Host webhook endpoints on port 80 or 443. *(`maxio-c4:createEndpoint.3`)*
- **silent**, -/side-effects (`client.CustomFields.CreateMetadata`, `client.CustomFields.UpdateMetadata`): Metadata is created or updated on a subscription or customer with a metafield name that does not exist yet → The metafield is created on the site as a text field with the given value. **Do:** Create metafields first (or change input_type afterwards with Update Metafield) when they should not be text fields. *(`maxio-c4:createMetadata.2`)*
- **silent**, -/webhooks (`client.CustomFields.CreateMetadata`, `client.CustomFields.UpdateMetadata`): A custom field value is added or changed on a subscription or customer (including at signup) → A custom_field_value_change webhook is fired. **Do:** Expect custom_field_value_change webhooks for your own metadata writes and avoid loops. *(`maxio-c4:createMetadata.4`)*
- **silent**, -/values (`client.CustomFields.CreateMetafields`, `client.CustomFields.UpdateMetafield`): enum values are sent for a metafield whose input_type is not radio or dropdown → enum applies only to radio and dropdown metafields. **Do:** Send enum only with input_type radio or dropdown. *(`maxio-c4:createMetafields.4`)*
- **silent**, -/side-effects (`client.CustomFields.CreateMetafields`, `client.CustomFields.UpdateMetafield`): A metafield's scope flags (csv, invoices, statements, portal, public_show, public_edit) are set to 1 → The metafield and its metadata are shown or exported in those places: CSV export, invoices, statements, the portal/Public Signup Pages, and viewable or editable in Embeddable Components. **Do:** Set each scope flag deliberately, since it controls where custom field data is shown to customers. *(`maxio-c4:createMetafields.7`)*
- **silent**, -/lists (`client.ApiExports.ListExportedProformaInvoices`, `client.ApiExports.ListExportedInvoices`, `client.ApiExports.ListExportedSubscriptions`): Exported rows are listed with per_page above 10000 → per_page is changed to 10000 (the default is 100). **Do:** Page through exported rows with per_page of at most 10000. *(`maxio-c4:listExportedProformaInvoices.1`)*
- **silent**, -/lists (`client.CustomFields.ListMetafields`, `client.CustomFields.ListMetadataForResourceType`): List Metafields or List Metadata for Resource Type is called without direction → Results are sorted by id ascending; direction=desc sorts descending. **Do:** Pass direction explicitly when the order matters. *(`maxio-c4:listMetafields.1`)*
- **silent**, limits/- (`client.WebhooksApi.ListWebhooks`, `client.WebhooksApi.ReplayWebhooks`): Webhook data is older than the site's webhook data retention limit → Advanced Billing stores webhook data only for a limited time (see Merchant Limits). **Do:** Do not rely on old webhooks being available to list or replay; keep your own record of what you need. *(`maxio-c4:listWebhooks.2`)*
