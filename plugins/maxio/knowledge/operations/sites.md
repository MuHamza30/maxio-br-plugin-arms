# Sites

## `client.Sites.ReadSite` — `GET /site.json` (`readSite`)

- **silent**, account-config/values: The site has Relationship Invoicing enabled → The response carries extra properties (customer_hierarchy_enabled, whopays_enabled, whopays_default_payer); multi_frequency_enabled is present only when relationship invoicing is active. **Do:** Treat the relationship-invoicing properties of the site as optional and expect them to be absent on other sites. *(spec `spec/openapi.yaml`; spec `spec/components/schemas/Site.yaml`; `maxio-c4:readSite.1`)*

## `client.Sites.ClearSite` — `POST /sites/clear_data.json` (`clearSite`)

- **loud**, account-config/errors: Clear Site Data is called on a site in live mode rather than test mode → 403 "FORBIDDEN". **Do:** Call Clear Site Data only against a site in test mode. *(spec `spec/openapi.yaml`; `maxio-c4:clearSite.1`)*
- **silent**, -/other: Clear Site Data is accepted → The data is deleted asynchronously, so products, customers and other records can still exist for a while after the call returns. **Do:** After clearing, wait and check that the site has no products or other records before continuing (for example in an automated test). *(spec `spec/openapi.yaml`; spec `spec/openapi.yaml`; `maxio-c4:clearSite.2`)*
- **silent**, -/side-effects: Clear Site Data is called with cleanup_scope=all (the default) → All products, customers and related subscriptions are cleared from the site. **Do:** Use cleanup_scope=customers when the product catalog must be kept. *(spec `spec/components/parameters/cleanup-scope.yaml`; `maxio-c4:clearSite.3`)*
- **silent**, -/side-effects: Clear Site Data is called with cleanup_scope=customers → Only customers and their related subscriptions are cleared; products are left untouched. **Do:** Expect the catalog to remain and recreate only customers and subscriptions after this clear. *(spec `spec/components/parameters/cleanup-scope.yaml`; `maxio-c4:clearSite.4`)*
- **silent**, -/side-effects: Site data is cleared (the sentence follows the customers scope in both places and may cover both scopes) → The site's revenue is reset to 0. **Do:** Do not expect revenue figures to survive a site data clear. *(spec `spec/components/parameters/cleanup-scope.yaml`; spec `spec/components/schemas/Cleanup-Scope.yaml`; `maxio-c4:clearSite.5`)*
- **silent**, order/other: A site is being moved from test to production (live) mode → Clearing the site data is necessary before the gateway processes real money. **Do:** Clear the site's test data before taking the site live. *(docs `content/introduction/basic-concepts/connected-sites.md`; `maxio-c4:clearSite.6`)*
