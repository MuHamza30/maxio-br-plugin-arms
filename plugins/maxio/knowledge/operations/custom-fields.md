## `client.CustomFields.CreateMetafields` — `POST /{resource_type}/metafields.json` (`createMetafields`)

- **loud**, limits/-: Creating a metafield (directly, by Update Metafield with a new current_name, or implicitly through metadata) would exceed 100 unique metafields for that resource type on the site → outcome not stated. **Do:** Keep at most 100 metafields for subscriptions and 100 for customers per site, and reuse existing metafields. - **loud**, -/errors: A metafield or metadata entry is sent without a name → 422 "'name' must be present to create or update metafields". **Do:** Always send name for every metafield and metadata entry. - **silent**, -/values: The enum list of a new metafield contains empty strings → Empty strings are not submitted as enum values.. **Do:** Do not rely on empty strings being stored as dropdown or radio options. *(spec `spec/components/schemas/Create-Metafield.yaml`; `maxio-c4:createMetafields.5`)*
- **silent**, -/values: A metafield is created without input_type → The metafield defaults to a text field.. **Do:** Send input_type explicitly when the metafield should be radio, dropdown or balance_tracker. *(spec `spec/components/schemas/Metafield-Input.yaml`; `maxio-c4:createMetafields.6`)*

## `client.CustomFields.CreateMetadata` — `POST /{resource_type}/{resource_id}/metadata.json` (`createMetadata`)

- **loud**, limits/-: A metadata (custom field) value is larger than 2 KB / 2048 characters → outcome not stated. **Do:** Keep custom field values within 2048 characters (2 KB).
