# Background: wallet-provisioning

- **silent**, account-config/side-effects (`background:wallet-provisioning`, `client.FeatureTemplates.CreateFeatureTemplate`, `client.FeatureTemplates.UpdateFeatureTemplate`): A Feature has wallet_behavior and a subscription resolves an entitlement to it → A wallet with origin feature is provisioned automatically; Create Wallet is never called for it. **Do:** Configure wallet_behavior on the Feature template instead of creating these wallets yourself. *(`maxio-c4:background.74`)*
- **silent**, state/side-effects (`background:wallet-provisioning`): The subscription that resolves a wallet-backed entitlement is still pending or awaiting signup → No wallet is provisioned until the subscription goes live. **Do:** Expect the feature wallet only after the subscription is live. *(`maxio-c4:background.75`)*
